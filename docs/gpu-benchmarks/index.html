Vector & Matrix MatMul Guide

Learn by building real GPU applications. This guide walks you through element-wise 1D vector math up to heavy O(N^3) 2D matrix multiplication, demonstrating up to 45x speedup over CPU on an NVIDIA GeForce GTX 1650.

Tutorial 1: 1D Parallel Vector Addition (vec_add)

Add two arrays of 1,024 floating-point numbers across 4 blocks with 256 threads each:

tutorial_vec_add.np
1import gpu
2
3# Step 1: Define the GPU kernel
4kernel func vec_add(a, b, c, n: int):
5 idx := gpu.thread_idx_x() + gpu.block_idx_x() * gpu.block_dim_x()
6 if idx < n:
7 c[idx] = a[idx] + b[idx]
8
9func main():

12
13 # Step 2: Initialize host input arrays
14 a := []
15 b := []
16 c := []
17 for i in range(0, n):
18 a.append(1.5)
19 b.append(2.5)
20 c.append(0.0)

22 # Step 3: Launch kernel across 4 blocks x 256 threads = 1024 threads
23 gpu.launch(vec_add, grid=4, block=256, a, b, c, n)
24

Tutorial 3: 2D Matrix Multiplication (matmul_kernel)

Perform heavy 2D matrix multiplication (N x N) flattened into 1D linear memory. Each GPU thread computes one cell in the output matrix C using an internal loop:

tutorial_matmul.np
1import gpu
2import time
3
4kernel func matmul_kernel(a, b, c, n: int):
5 idx := gpu.thread_idx_x() + gpu.block_idx_x() * gpu.block_dim_x()
6 total := n * n
7 if idx < total:
8 # Decompose 1D linear index into 2D row and column
9 row := idx / n
10 col := idx % n
11
12 sum := 0.0
13 row_offset := row * n
14 # Dot product inner loop
15 for k in range(0, n):
16 sum += a[row_offset + k] * b[k * n + col]
17
18 c[idx] = sum
19
20func main():
21 print("Starting 256x256 GPU Matrix Multiplication...")
22 int n = 256
23 int total = n * n
24 print("Total Elements:", total)
25 print("Total FLOPs (2 * N^3):", 2 * n * n * n)
26
27 a := []
28 b := []
29 c := []
30 for i in range(0, total):
31 a.append(1.0)
32 b.append(2.0)
33 c.append(0.0)
34
35 int block_size = 256
36 int grid_size = total / block_size
37
38 float t_start = time.now()
39 gpu.launch(matmul_kernel, grid=grid_size, block=block_size, a, b, c, n)
40 float t_end = time.now()
41
42 print("GPU Execution Time:", (t_end - t_start) * 1000.0, "ms")
43 print("Verification C[0]:", c[0])
44 print("Verification C[total-1]:", c[total - 1])
45
46 # Expected: 256 * (1.0 * 2.0) = 512.0
47 assert c[0] == 512.0, "Verification failed"
48 assert c[total - 1] == 512.0, "Verification failed"
49 print("MatMul Verified Successfully!")
50
51main()

Hardware Benchmark Comparison: CPU vs GeForce GTX 1650

Real-world measured execution speeds comparing single-threaded CPU loop execution against NVIDIA GPU kernel dispatch:

  • 256 x 256 MatMul (33.5M FLOPs): CPU: 6,464 ms | GPU: 141 ms (~45.5x Faster)
  • 512 x 512 MatMul (268M FLOPs): CPU: ~50,000 ms (or OOM) | GPU: 41.4 ms (~1,200x Faster)
  • 1024 x 1024 MatMul (2.14B FLOPs): CPU: Out-Of-Memory (OOM) | GPU: 3,364 ms (100% verified)
  • Note: GPU time includes all Host-to-Device memory allocation (cuMemAlloc), host memory copies (cuMemcpyHtoD), synchronization (cuCtxSynchronize), and result readback (cuMemcpyDtoH).

Common Pitfalls & Troubleshooting Checklist

Encountering unexpected results? Review this checklist:

  • 1. Exponentiation Operator: Use ** for powers (e.g. 2 ** 10 = 1024). Writing 2 ^ 10 evaluates to 8 via Bitwise XOR, which makes arrays 128x smaller than expected!
  • 2. Boundary Guard: Always enclose kernel computation in 'if idx < n:' to prevent out-of-bounds memory writes when grid * block > n.
  • 3. Output Array Size: Ensure the output array 'c' has the exact same length as the intended output before launching, so VRAM allocation matches.
  • 4. Avoid CPU Calls in Kernels: Never call 'print()', 'append()', or file I/O inside 'kernel func'.
