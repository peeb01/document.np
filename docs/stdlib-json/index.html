Standard Library

json Module (Serialization)

The json module provides bi-directional conversion between JSON text and native NP dictionary/array data structures.

json.parse(string source)

signature|fn json.parse(string source) -> var

Parses a valid JSON string and returns the rebuilt nested dict or array object.

Parameters
sourcestring

The JSON encoded string to parse.

Returns:var (dict | array)The parsed dictionary or array.
parse_demo.np
1import "json"
2
3string raw_json = "{\"service\": \"auth\", \"port\": 9000, \"roles\": [\"admin\", \"user\"]}"
4
5dict data = json.parse(raw_json)
6print("Service Name:", data["service"])
7print("Port Number:", data["port"])
8print("First Role:", data["roles"][0])
Expected Terminal Outputstdout
Service Name: auth
Port Number: 9000
First Role: admin

json.stringify(var value)

signature|fn json.stringify(var value) -> string

Serializes a dictionary, array, or primitive variable into a compact JSON string.

Parameters
valuedict | array | var

The data structure to serialize.

Returns:stringThe serialized JSON string.
stringify_demo.np
1import "json"
2
3dict payload = {
4 "success": true,
5 "code": 200,
6 "items": ["cpu", "memory", "disk"]
7}
8
9string json_str = json.stringify(payload)
10print("JSON Output:", json_str)
Expected Terminal Outputstdout
JSON Output: {"code":200,"items":["cpu","memory","disk"],"success":true}
