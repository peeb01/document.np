Concurrency & Pure Threads

NP provides a modern, pure multi-threading model designed for effortless parallel execution. Simply import 'threads' to inspect hardware execution cores, spawn asynchronous worker tasks with threads.run(), synchronize results via task.wait(), and configure memory safety (isolated=true) to eliminate race conditions.

1. The Pure Threads Philosophy

Unlike complex actor frameworks or low-level channel boilerplate, NP treats concurrency as first-class asynchronous function dispatching with automated future synchronization:

  • Zero Boilerplate: No channel allocation or manual mutex locks required. Just write standard functions and pass them to threads.run().
  • Hardware-Aware: Directly queries the machine's hardware execution cores via threads.num_cpu() to dimension workloads dynamically.
  • Configurable Memory Isolation: Choose between blazing C-speed zero-copy pointer sharing (isolated=false) or 100% race-condition-free shared-nothing isolation (isolated=true).
  • Future Synchronization: Every thread returns a lightweight Task future handle. Simply call task.wait() to block and retrieve the result.

2. Quick Start: threads.run & task.wait()

signature|fn threads.run(func worker, ...args, bool isolated = false) -> Task

Spawn any function asynchronously on an OS thread and retrieve its return value:

Parameters
workerfunction

Target function identifier to execute asynchronously.

...argsany

Positional arguments passed to the worker function.

isolatedbool

If true, arguments are deep-cloned to guarantee 100% race-condition-free execution.

Returns:TaskA concurrent task future. Call task.wait() to block and retrieve the function return value.
threads_quickstart.np
1import threads
2import time
3
4func compute_square(int n) -> int:
5 time.sleep(0.05)
6 return n * n
7
8func main():
9 print("Available CPU cores:", threads.num_cpu())
10
11 # Spawn background task
12 print("Spawning worker task...")
13 task := threads.run(compute_square, 12)
14
15 print("Main thread running other operations concurrently...")
16
17 # Wait for result
18 res := task.wait()
19 print("Square result:", res)
20
21main()

3. Direct Invocation & Flexible Synchronization: threads(fn)

NP allows calling the threads module directly as a function for concise syntax, and synchronizing with either method or functional syntax:

  • threads(worker, ...args): Callable module shorthand equivalent to threads.run(worker, ...args).
  • task.wait(): Method call syntax on the Task instance.
  • threads.wait(task): Functional module utility equivalent to task.wait().
  • threads.num_cpu: Property access without parentheses.
threads_shorthand.np
1import threads
2
3func greet_async(string name) -> string:
4 return "Hello from thread, " + name + "!"
5
6func main():
7 # Direct callable module invocation
8 task := threads(greet_async, "NP Developer")
9
10 # Functional wait syntax
11 message := threads.wait(task)
12 print(message)
13
14main()
Expected Terminal Outputstdout
Hello from thread, NP Developer!

4. Configurable Race Condition Management: isolated=true

Configure memory safety per thread call: choose between raw C-speed zero-copy pointer sharing or 100% race-condition-free execution:

  • isolated = false (Default): High-Performance / C-Speed. Passes memory pointers directly with zero copy overhead. Ideal for read-heavy workloads or large datasets.
  • isolated = true: Shared-Nothing / Memory Isolation. The NP runtime recursively deep-clones all arguments before starting the thread. Mutations inside the worker never affect caller data, eliminating race conditions entirely.
race_condition_safe.np
1import threads
2
3func modify_list(items) -> int:
4 items.append(999)
5 return items.len()
6
7func main():
8 # 1. Isolated Execution: Caller state is completely protected
9 safe_list := [1, 2, 3]
10 task_iso := threads.run(modify_list, safe_list, isolated = true)
11 print("Isolated worker list length:", task_iso.wait())
12 print("Caller list length remains:", safe_list.len())
13
14 # 2. Shared Execution: Zero-copy in-place modification
15 shared_list := [10, 20, 30]
16 task_shared := threads.run(modify_list, shared_list)
17 print("Shared worker list length:", task_shared.wait())
18 print("Caller list modified in-place:", shared_list.len())
19
20main()
Expected Terminal Outputstdout
Isolated worker list length: 4
Caller list length remains: 3
Shared worker list length: 4
Caller list modified in-place: 4

Memory Safety Trade-off

Deep-copying massive datasets (e.g. 100M items) consumes RAM and CPU time. Use isolated=false for zero-copy read pipelines, and isolated=true when safe state isolation is mandatory.
